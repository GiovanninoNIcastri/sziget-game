# 📸 Foto per il Festival Game

## Come aggiungere le tue foto:

1. **Prendi le foto** di ognuno di voi 4
2. **Rinominale** come:
   - `person1.jpg` (o .png)
   - `person2.jpg` (o .png) 
   - `person3.jpg` (o .png)
   - `person4.jpg` (o .png)
3. **Mettile in questa cartella** (`images/`)

## Specifiche consigliate:
- **Formato**: JPG o PNG
- **Dimensione**: 300x300 pixel (o quadrata)
- **Qualità**: Buona risoluzione
- **Stile**: Foto del viso, possibilmente sorridenti! 😊

## Effetti speciali:
- Le foto appariranno come **cerchi** con bordi colorati
- Durante la selezione si **ingrandiranno** con effetti luminosi
- Se non carica la foto, apparirà un emoji 👤 come fallback

## Esempio di struttura:
```
images/
├── person1.jpg  (Foto di Persona 1)
├── person2.jpg  (Foto di Persona 2)
├── person3.jpg  (Foto di Persona 3)
└── person4.jpg  (Foto di Persona 4)
```

**Divertiti! 🎪✨**
